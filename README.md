# Mi Tarea de Git y GitHub

## 1. Qué aprendí del video
Aprendí a utilizar los conceptos básicos de Git para el control de versiones local, cómo inicializar un repositorio, preparar archivos con "add" y guardarlos de forma segura mediante "commits". También comprendí cómo conectar mi entorno local con un repositorio remoto en GitHub para subir mis proyectos a la nube.
